# Atualizações da documentação {#latest-updates}

Esta página lista todas as atualizações da documentação do Adobe Campaign Web.

## Junho de 2026 {#june-2026}

* Adição de uma observação sobre os requisitos de codificação para entregas de correspondência direta direcionadas a idiomas CJK (japonês, coreano, chinês simplificado, chinês tradicional). A codificação padrão Latin-1 (1252) não pode representar caracteres CJK, resultando em uma visualização de arquivo vazia. Os usuários devem selecionar UTF-8 (65001) nas configurações de Formato de extração. [Leia mais](../direct-mail/content-direct-mail.md)
* Adicionada uma página sobre as diretrizes da CNIL para pixels de rastreamento de email e os recursos relacionados do Adobe Campaign. [Leia mais](https://experienceleague.adobe.com/pt-br/docs/campaign/campaign-v8/new/cnil-pixel-tracking){target="_blank"}

## Dezembro de 2025 {#december-2025}

**Data: 1.º de dezembro de 2025**

* Reorganizamos o guia de documentação do recurso Gerar conteúdo com páginas consolidadas para [geração de conteúdo completo](../content/generative-full-content.md), [geração de texto](../content/generative-text.md) e [geração de imagens](../content/generative-image.md)
* Adicionado o [Guia de práticas recomendadas para prompts do recurso Gerar conteúdo](../content/ai-assistant-prompting-guide.md) para ajudar os usuários a criar prompts eficazes
